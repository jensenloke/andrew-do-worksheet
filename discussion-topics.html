Fixed leveling assumptions — bake into every agent (from the organizer)
  1. No claims — Q17 = 0, Q18 = No, Q19 = No. No loss run.
  2. New policy, no current coverage — Q20 (expiring premium) = 0; rate change not meaningful.
  3. Employee headcount = 200 — regardless of the real figure.
  4. Everything else from the insured's website — public FS, share price, shareholding, board, SGX announcements.

Decisions to make

1

Agent scope on stage

Full end-to-end underwriting, or agent does research/data-entry while humans make the judgement calls live?

Open
Recommendation: Full end-to-end, framed as “the agent underwrites, the human governs.” The agent produces the complete worksheet (narrative → 20 answers → modifiers with cited facts → exclusions → premium → referral status), then Jensen spends 2–3 minutes in visible adversarial review — checking the cited facts, pushing back where it got something subtly wrong.
Why this over the alternatives
  • Doing judgement by hand on stage spends half your ~12–15 minutes operating a spreadsheet — what the audience already does.
  • “AI as research assistant” is the story insurers already believe; the organizer wants a different perspective.
  • In a three-way prompt fight, augmentation is the least ambitious entry.
  • Pure unattended automation risks one visibly wrong judgement call sinking credibility — so make the human review an explicit governance step, not a crutch.
Decision / notes
2

One client or three?

Do all three agents run on the same insurer-picked client, or does each presenter get their own?

Open
Recommendation: Same client for all three. It makes the head-to-head comparison clean and is the honest “prompt fight.” Needs confirmation from the organizer.

3

Rehearsal client shortlist

Which real SGX-listed companies to rehearse on? Need coverage across hazard classes 1–4.

Open
Recommendation: ComfortDelGro (C52, Class 2 baseline) · City Developments or UOL (Class 3) · Seatrium (5E2, Class 4 stress — 2024 CAD investigation exercises Q14/referral) · CapitaLand Integrated Commercial Trust (C38U, Class 1). Plus the Marina Logistics worked example as the deterministic smoke test.
What each tests
  • Class 1 (REIT) — the low-drama floor; cheap premium, minimal referrals.
  • Class 2 (transport) — a calm, large-ish cap baseline.
  • Class 3 (property) — cyclical, estimate-heavy accounting; tests hazard classification.
  • Class 4 (offshore/marine) — adverse history + regulatory trigger; tests how the agent handles a live investigation and whether it refers.

Time budget

One hour shared across host + 3 presenters + Q&A. How do we split it, and how fast must the agent run?

Open
Recommendation: ~12–15 min per presenter: ~1 min framing → 5–6 min agent run → ~3 min output walkthrough → ~3 min design + risks/issues/costs. So the agent must finish a full run in under 6 minutes — parallel research fetches and pre-baked factor tables.
